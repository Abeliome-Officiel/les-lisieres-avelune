## Détails

### DEC-001 — Jeu sur navigateur

Le jeu est accessible depuis un navigateur et pensé dès le départ pour le téléphone.

- Statut : **Décision définitive**
- Priorité : **Critique**
- Phase : **MVP**
- Dépendance : Tous

### DEC-002 — Aucun conflit entre joueurs

Aucun PvP, pillage, attaque de territoire ou destruction provoquée par un autre joueur.

- Statut : **Décision définitive**
- Priorité : **Critique**
- Phase : **MVP**
- Dépendance : Social

### DEC-003 — Entraide structurelle

Toute contribution aide le monde; l’entraide est intégrée aux systèmes sans imposer une sociabilité constante.

- Statut : **Décision définitive**
- Priorité : **Critique**
- Phase : **Prototype**
- Dépendance : Boucle centrale

### DEC-004 — Faible importance du niveau

L’ancienneté donne davantage d’options et d’automatisation mais ne rend jamais les nouveaux inutiles.

- Statut : **Décision définitive**
- Priorité : **Critique**
- Phase : **Prototype**
- Dépendance : Équilibrage

### DEC-005 — Gestion, bac à sable, chill mais intense

Le jeu permet des sessions calmes ou engagées, avec profondeur de gestion et événements intenses.

- Statut : **Décision définitive**
- Priorité : **Haute**
- Phase : **MVP**
- Dépendance : Interface

### DEC-006 — Collection sans prédation

La collection soutient le retour au jeu sans microtransaction aléatoire, FOMO ou punition d’absence.

- Statut : **Décision définitive**
- Priorité : **Critique**
- Phase : **MVP**
- Dépendance : Économie

### DEC-007 — Tower defense contre le monde

La défense vise des phénomènes du jeu; les vagues peuvent être combattues, canalisées, accueillies ou transcendées.

- Statut : **Décision définitive**
- Priorité : **Critique**
- Phase : **Prototype**
- Dépendance : Événements

### DEC-008 — Diversité des vagues

Les vagues peuvent être hostiles, positives, ambiguës, environnementales, sociales, culturelles ou logistiques.

- Statut : **Décision définitive**
- Priorité : **Critique**
- Phase : **Prototype**
- Dépendance : Contenu

### DEC-009 — Effets ponctuels ou persistants

Un événement peut modifier temporairement ou durablement un territoire, un réseau, une région ou le monde.

- Statut : **Décision définitive**
- Priorité : **Haute**
- Phase : **Prototype**
- Dépendance : Persistance

### DEC-010 — Échos locaux

Des pseudo-fractures locales adaptées au style du joueur peuvent apparaître dans son territoire.

- Statut : **Décision provisoire**
- Priorité : **Haute**
- Phase : **Prototype**
- Dépendance : Directeur adaptatif

### DEC-011 — Événements positifs

Les phénomènes favorables, féeriques, fertiles ou culturels sont aussi importants que les menaces.

- Statut : **Décision définitive**
- Priorité : **Haute**
- Phase : **Prototype**
- Dépendance : Ton

### DEC-012 — Directeur adaptatif

Le monde observe les stratégies dominantes et varie progressivement ses réponses sans tricher.

- Statut : **Décision provisoire**
- Priorité : **Haute**
- Phase : **Après MVP**
- Dépendance : Télémétrie

### DEC-013 — Victoires graduées

Les résultats vont de la stabilisation à la transcendance; un échec tactique crée une suite jouable et peu de pertes.

- Statut : **Décision définitive**
- Priorité : **Critique**
- Phase : **Prototype**
- Dépendance : Boucle centrale

### DEC-014 — Plusieurs rôles complémentaires

Protection, soin, action, contrôle, logistique, exploration, médiation, art et passe-brèche sont utiles.

- Statut : **Décision définitive**
- Priorité : **Haute**
- Phase : **Prototype**
- Dépendance : Personnage

### DEC-015 — Passe-brèche

Le rôle de roublard devient spécialiste d’infiltration, récupération, chemins temporaires et prise de risque contrôlée.

- Statut : **Décision définitive**
- Priorité : **Moyenne**
- Phase : **MVP**
- Dépendance : Éclats

### DEC-016 — Reconversion souple

Changer de spécialité conserve les acquis transversaux; la transition prend du temps mais ne remet pas à zéro.

- Statut : **Décision définitive**
- Priorité : **Haute**
- Phase : **MVP**
- Dépendance : Arbres de progression

### DEC-017 — Plusieurs voies de réussite

Productivité, résilience, beauté, hospitalité, culture, savoir, exploration et biodiversité sont des accomplissements valides.

- Statut : **Décision définitive**
- Priorité : **Haute**
- Phase : **MVP**
- Dépendance : Tycoon

- Statut : **Décision définitive**
- Priorité : **Haute**
- Phase : **Vision**
- Dépendance : Identité

- Phase : **Vision**
