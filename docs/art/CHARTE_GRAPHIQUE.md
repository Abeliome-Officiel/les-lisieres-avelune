# Charte graphique de travail — Les Lisières d’Avelune

Statut : **direction actuelle de travail**, non définitive.

Cette charte sert à maintenir une continuité entre le prototype, la documentation et les futurs visuels sans figer prématurément la direction artistique finale.

## 1. Intention visuelle

Avelune doit évoquer un monde :

- poétique ;
- féerique ;
- onirique ;
- organique ;
- minéral ;
- floral dans ses formes et dynamiques de croissance ;
- queer dans sa sensibilité à la fluidité, à l’ambiguïté et aux identités non normatives ;
- contemplatif mais pas passif ;
- systémique sans esthétique technologique froide ;
- mystérieux sans devenir grimdark ;
- accueillant sans supprimer le challenge.

L’image doit pouvoir faire coexister matière, architecture organique, réseaux, circulation d’énergie/matière/connaissance et grandes structures du monde : Fracture, anneaux, Lisière, Corcites.

## 2. Canon visuel provisoire

La nature de la population vivant dans les Corcites **n’est pas définie**.

L’existence, la nature et la place d’une éventuelle faune ou flore extérieure ne sont pas non plus suffisamment définies pour devenir canoniques.

En conséquence, jusqu’à décision explicite, les visuels officiels ou semi-officiels ne doivent pas représenter :

- humains ;
- humanoïdes ;
- silhouettes anthropomorphes suggérant une population définie ;
- peuples ou habitants inventés ;
- animaux ou créatures supposées canoniques ;
- faune inventée ;
- espèces florales naturalistes présentées comme flore définie d’Avelune.

Cette règle vaut pour les bannières, illustrations GitHub, fonds du jeu, concepts, icônes narratives et visuels promotionnels.

### Ce qui peut être représenté

- Fracture ;
- Lisière ;
- anneaux et arcs ;
- paysages non peuplés ;
- Corcites et architectures organiques **non anthropomorphes** ;
- minéraux, cristallisations et matières ;
- réseaux lumineux ;
- flux et phénomènes ;
- motifs hexagonaux discrets ;
- ramifications, corolles abstraites et structures évoquant la croissance sans fixer une biologie ;
- traces, cicatrices, mémoire et transformations du monde.

## 3. Sensibilité queer

La dimension queer fait partie de l’identité du projet, mais ne doit pas être réduite à une signalétique littérale.

Elle peut se traduire par :

- fluidité des formes ;
- transitions, métamorphoses et états intermédiaires ;
- asymétries harmonieuses ;
- coexistence de formes non normatives ;
- iridescences ;
- ambiguïtés d’échelle ou de matière ;
- pluralité plutôt qu’un modèle unique de beauté ou d’organisation.

La couleur peut s’en teinter sans tomber dans une reproduction systématique de drapeaux.

### Orientation chromatique

La direction doit désormais tirer **davantage vers le violet que vers le bleu**.

À privilégier :

- prune sombre ;
- violet crépusculaire ;
- lavande ;
- mauve grisé ;
- indigo en soutien ;
- iridescences violet/rose/vert à faible saturation ;
- verts organiques ou minéraux ;
- ors doux pour certains foyers, seuils, Fracture ou éléments vitaux.

Le bleu froid et le teal restent possibles mais ne doivent plus dominer l’identité générale.

## 5. Typographie

### Interface

Police actuelle : **Inter**, avec fallbacks système sans-serif.

Elle reste la référence pour :

- UI ;
- tableaux ;
- formulaires ;
- données ;
- documentation technique ;
- textes nécessitant une grande lisibilité.

### Titrage / key art

Une typographie plus littéraire ou organique peut être utilisée dans les visuels de vitrine, mais elle n’est **pas encore figée comme police officielle du jeu**.

Le contraste recherché :

- interface claire et lisible ;
- titrage plus poétique et identitaire.

## 6. Motifs visuels

À privilégier avec mesure :

- structures hexagonales discrètes ;
- anneaux et arcs concentriques ;
- réseaux lumineux ;
- ramifications organiques ;
- textures minérales ;
- corolles et croissances abstraites ;
- architecture vivante intégrée au paysage ;
- noyaux et foyers doux ;
- fracture lumineuse lointaine ;
- Lisière comme frontière vitale et commune ;
- Corcites distincts pouvant être reliés, proches ou autonomes.

## 7. Collaboration et monde partagé

Les visuels doivent pouvoir représenter simultanément deux idées :

1. **tout le monde contribue à la protection globale de la Lisière** ;
2. **la coopération directe entre Corcites reste facultative**.

Cette idée doit être exprimée par la géographie, les flux, les Corcites, leurs réseaux et leurs effets sur la Lisière — **pas par un groupe de personnages rassemblés**.

Des Corcites peuvent :

- collaborer directement ;
- échanger ;
- agir en parallèle ;
- se spécialiser ;
- rester très autonomes ;
- contribuer néanmoins au résultat collectif du monde.

## 8. À éviter

- humains/humanoïdes tant que leur existence n’est pas définie ;
- faune ou flore naturaliste non actée ;
- fantasy médiévale générique ;
- grimdark dominant ;
- militarisation visuelle excessive ;
- interfaces saturées de récompenses et badges ;
- néons cyberpunk agressifs ;
- esthétique technique froide qui ferait disparaître l’organique ;
- infantilisation visuelle sous prétexte d’accessibilité ;
- iconographie genrée par défaut ;
- usage décoratif superficiel de codes queer sans cohérence avec l’univers.
