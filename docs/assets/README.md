# Assets visuels

Ce dossier contient uniquement les visuels légers réellement utilisés par la documentation GitHub.

## Statut

Les visuels sont des **directions artistiques de travail**, pas des éléments définitifs du jeu.

Le précédent visuel de bannière du README a été retiré : il introduisait des figures humaines/humanoïdes alors que la nature de la population d’Avelune n’est pas encore définie, et son affichage GitHub était cassé.

Aucune nouvelle bannière n’est considérée canonique pour le moment.

## Règle de représentation actuelle

Jusqu’à décision de conception explicite, les visuels destinés au projet ne doivent pas inventer :

- humains ou humanoïdes ;
- habitants ou peuples ;
- faune ;
- créatures ;
- espèces florales naturalistes présentées comme canoniques.

La direction actuelle privilégie Fracture, Lisière, Corcites non anthropomorphes, architectures organiques, minéraux, matières, réseaux, motifs de croissance abstraits et paysages non peuplés.

Les sources haute définition, références et variantes sont conservées dans :

`Avelune/05_Direction_artistique_et_visuels/`
