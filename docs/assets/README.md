# Assets visuels

Ce dossier contient les visuels légers destinés à la documentation GitHub.

## Statut

Les visuels présents sont des **directions artistiques de travail**, pas des assets définitifs du jeu.

- `avelune-readme-hero.webp` : visuel vitrine actuel du README ; il illustre la dimension féerique, organique, systémique et collective d’Avelune, notamment la protection commune de la Lisière et la coexistence de Corcites plus ou moins coopératifs.

Les sources haute définition et variantes sont conservées dans le dossier Google Drive `Avelune/05_Direction_artistique_et_visuels/`.

Voir aussi [`../art/CHARTE_GRAPHIQUE.md`](../art/CHARTE_GRAPHIQUE.md).
