# PROTO-0.2 — Décisions nécessaires

Aucune décision bloquante connue au lancement du long run Codex du 2026-08-07.

Les anciennes questions sur connexions directes, réseau productif, quatre familles de tours, captation/matière de vague, stockage natif, réserve énergétique courte et nombre fixe de trois vagues sont **closes ou hors périmètre** par les sources de rang supérieur.

## Points réellement encore ouverts mais non bloquants

- Nature détaillée future de l’onde : composition et 4 à 6 caractéristiques à définir prochainement pour le jeu, pas pour le challenge actif PROTO-0.2.
- Équilibrage numérique de laboratoire : coûts, puissance initiale, croissance, efficacité d’Affaiblissement, dégâts d’Intégrité, cadence cachée. Codex est autorisé à les calibrer par simulation sans les considérer comme canon définitif.
- Consommation exacte d’entretien d’une fonction OFF ou sans personnel si le comportement existant ne peut pas être conservé proprement.
- Conséquence future d’une baisse externe de capacité énergétique sous la charge active ; hors besoin immédiat si aucune mécanique P02 ne provoque ce cas.
