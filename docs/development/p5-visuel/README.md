# P5A VISUEL

Baseline propre du chantier **VISUEL** aval d’Avelune.

Cette baseline est reconstruite depuis `main` et la frontière P1 qualifiée. Les anciennes branches VISUEL restent des références historiques et ne sont pas des dépendances.

## Règle de méthode

Ordre de conservation :

1. lois et frontières d’Avelune ;
2. invariants perceptifs et artistiques ;
3. connaissances, résultats de tests et mesures ;
4. références scientifiques, artistiques et techniques ;
5. contrats qualifiés ;
6. code existant uniquement s’il reste naturellement compatible et simplifie le système.

Un ancien prototype peut donc être conservé comme preuve ou comparaison sans être réutilisé dans la baseline.

## Périmètre P5A

P5A produit :

- `VisualPayload` ;
- consommation de la frontière P1 ;
- fixtures et replays sémantiques offline ;
- mémoire visuelle aval ;
- grammaire visuelle ;
- préférences **visuelles et sensorielles** utilisateur ;
- ports de renderer ;
- renderers de laboratoire ;
- tests, benchmarks et dossier de qualification.

P5A ne produit pas :

- le Cœur ;
- la projection source privée P1 ;
- la musique ou le sonore ;
- l’observabilité P2 ;
- l’orchestration P3 ;
- le Tableau P4 ;
- l’assemblage produit de la Fenêtre, propriété de P6.

## Préférences utilisateur

Les préférences propres à l’observateur sont ici **exclusivement visuelles** : mouvement, pulsation, parallaxe, particules, halos, flashes, contraste, saturation, grain, profondeur, niveau de détail et autres dimensions perceptives justifiées par les essais.

Elles modifient la présentation, jamais l’état canonique, l’identité, la chronologie ou les faits du monde.
