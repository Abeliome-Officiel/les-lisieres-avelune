# Consolidation de conception post-v0.8

Ce dossier rassemble les décisions de conception prises après la publication de
la v0.8. Il conserve à la fois les consolidations pré-prototype, les remises à
plat rendues nécessaires par les premiers playtests logiciels et le registre
long terme « Futur du jeu ».

Il sert de couche de consolidation entre la documentation historique v0.8, les
prototypes successifs et les arbitrages de conception issus des playtests.

## Règle d'autorité

Lorsqu'un élément décrit dans ce dossier remplace explicitement une règle plus
ancienne, la version la plus récente de ce dossier prévaut.

Les documents historiques ne sont pas supprimés : ils conservent la trace de
l'évolution de la conception.

Le registre « Futur du jeu » ne transforme jamais une piste en décision : le
statut attaché à chaque idée reste déterminant.

## Jalons

- v0.8.1 : consolidation des mécaniques TD, TF et RPG ;
- v0.8.2 : identité, progression, monde et connaissance ;
- v0.8.3 : baseline générale pré-prototype ;
- v0.8.4 : remise à plat TF, ergonomie, énergie et modèle mental après playtest du PROTO-0.1 — voir `04_tf_ergonomie_et_modele_mental_2026-08-06.md` ;
- 7 août 2026 : intégration dans GitHub du registre des idées, hypothèses et développements futurs — voir `05_futur_du_jeu_registre_2026-08-07.md`.

## Registre long terme

- [`05_futur_du_jeu_registre_2026-08-07.md`](05_futur_du_jeu_registre_2026-08-07.md) : synthèse GitHub du pool « Futur du jeu », delta post-v0.3 des 6–7 août 2026, points encore ouverts et section séparée d'idées extrapolées par ChatGPT explicitement non validées.
- baseline archivistique : `Avelune_Pool_idees_futur_jeu_v0.3.pdf`, 313 entrées au 3 août 2026, conservée dans le Drive du projet.

## Statuts utilisés

- **Acté** : décision retenue dans le socle courant.
- **Déduit** : conséquence logique d'une décision actée.
- **Proposé** : piste suffisamment définie pour être étudiée.
- **Ouvert** : arbitrage encore nécessaire.
- **Remisé** : conservé pour une version ultérieure.
- **Hors périmètre** : volontairement exclu du jalon considéré.
- **Extrapolation assistant** : idée produite par ChatGPT à partir du corpus ; aucune valeur canonique avant validation humaine.

Les documents de ce dossier peuvent intégrer des décisions de game design prises
après observation du prototype lorsqu'elles corrigent le modèle mécanique ou le
modèle mental du joueur. Les détails purement logiciels restent documentés dans
`docs/development/` et `docs/proto0/`.
