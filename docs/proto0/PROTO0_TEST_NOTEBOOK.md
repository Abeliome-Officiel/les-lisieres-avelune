# PROTO-0 — Carnet de test

Statut : **[acté] — Lot 12**

## But

Le carnet accompagne le playtest sans transformer l'expérience en formulaire permanent.

Chaque note comporte :

- une catégorie ;
- un texte libre ;
- le tour courant ;
- la vague concernée ;
- la phase du cycle ;
- l'intégrité ;
- la réserve énergétique ;
- la dette d'entretien ;
- le dernier message d'état de la session.

## Catégories

- Stratégie
- Intention
- Friction
- Surprise
- Bug
- Autre

## Persistance

Les notes sont conservées localement dans le navigateur et peuvent être exportées en JSON.

Le carnet sert au playtest et à l'analyse. Il ne constitue pas une mécanique diégétique définitive du jeu.
