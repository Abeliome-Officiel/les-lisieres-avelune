# Catalogue fonctionnel du prototype v0.9-dev.3

## Objet

Le catalogue contient uniquement les éléments nécessaires pour tester le cœur
des axes TD, TF et RPG et leurs premières interactions.

## Convention temporaire

- une lettre distingue une famille ;
- un nombre indique le niveau ;
- niveau 0 : ressource de base ;
- niveau 1 : première transformation ;
- niveau 2 : production avancée.

Exemple :

```text
Matériau A0 → Produit A1 → Avancé A2
```

## Fiche homogène

Chaque élément possède notamment :

- identifiant stable ;
- nom affiché ;
- axe, type, famille et niveau ;
- fonction ;
- prérequis et besoins ;
- coûts, entrées et sorties ;
- conséquences ;
- domaines et cibles d’impact ;
- facteurs et formule ;
- durée et conditions ;
- règles de cumul ;
- intégrité éventuelle ;
- interactions ;
- image, icône et texte alternatif ;
- statut de test, version et notes d’équilibrage.

## Périmètre

- 9 ressources TF ;
- 10 bâtiments TF ;
- 4 défenses TD ;
- 3 vagues TD ;
- 4 caractéristiques RPG ;
- 6 compétences RPG.

Les valeurs sont provisoires. Le contenu futur sera ajouté sous forme de listes
sans modifier le principe du moteur.
