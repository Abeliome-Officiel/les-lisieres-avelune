# Trame d’Avelune — version de production

## Procédure RPG partageable

1. Aucun jet si l’action est acquise et sans incertitude intéressante.
2. Choix structuré si l’enjeu est principalement social, moral ou interprétatif.
3. Test d100 si une compétence peut modifier réellement l’issue.
4. Piste de progression pour une scène longue.
5. Toute conséquence produit une nouvelle piste, un coût, une condition ou une information.

## Seuil d100

`caractéristique + compétence + objet + difficulté + condition`, borné entre 5 et 95 dans l'ancienne baseline.

- réussite remarquable : jet très inférieur au seuil ;
- réussite complète : jet inférieur ou égal au seuil ;
- réussite avec coût : échec dans une faible marge ;
- conséquence : échec plus important.

La position fixe la gravité ; l’effet fixe l’ampleur.

Ces règles restent une baseline de travail et peuvent évoluer avec la préproduction.

## Dissonance

La **Dissonance** reste un concept RPG à revalider.

Les anciennes échelles, noms de paliers, conditions de Bascule, relations cachées avec les transformations et conséquences profondes ont été déplacés dans le **Codex secret / Cœur d’Avelune**.

Si une partie de ces informations devient nécessaire à la prise de décision du joueur, elle devra être redocumentée explicitement comme règle player-facing plutôt que révélée accidentellement depuis une ancienne spécification.
