# Interface intégrée du prototype v0.9-dev.3

## Fonction

Cette interface expose le moteur intégré sans ajouter de contenu massif.

Elle permet :

- la configuration d’une session ;
- le pilotage de quatre ou six corps-cités ;
- la sélection d’un ordre TD, TF et RPG par cité et par tour ;
- l’affichage des stocks, bâtiments, défenses et fiches RPG ;
- la lecture simple des anneaux ;
- l’avancement manuel de la vague ;
- la copie et le téléchargement du journal complet.

## Accessibilité

Un bouton flottant « Affichage » ouvre des réglages combinables :

- profil sombre ou clair ;
- profil de lecture personnalisable ;
- profil de faible stimulation ;
- choix de famille de police ;
- taille du texte ;
- hauteur de ligne ;
- espacement des lettres et des mots ;
- longueur de ligne ;
- suppression de l’italique ;
- réduction des mouvements ;
- contraste renforcé ;
- mise en évidence de la tâche active.

Les profils sont des points de départ et ne prétendent pas définir un besoin
unique pour toutes les personnes dys, TSA ou TDAH.
